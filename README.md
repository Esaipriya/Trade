## 🧠 Steps Followed
1. **Data Collection**  
   - Loaded both datasets (Trader Data & Sentiment Data) from provided Google Drive links.

2. **Data Cleaning & Preprocessing**  
   - Converted timestamps to datetime format.  
   - Handled missing values and duplicates.  
   - Normalized column names and merged datasets on `Date`.

3. **Exploratory Data Analysis (EDA)**  
   - Analyzed sentiment distribution over time.  
   - Examined correlations between trader profitability and sentiment.  
   - Compared average leverage, volume, and closed PnL across sentiment phases.

4. **Visualization**  
   - Time-series trends for fear/greed cycles.  
   - Scatter plots and boxplots showing trading metrics vs. sentiment.

5. **Insights & Conclusion**  
   - Identified behavioral shifts during fear vs. greed periods.  
   - Summarized actionable trading insights.
